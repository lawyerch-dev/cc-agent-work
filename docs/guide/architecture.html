Architecture

技术内核：一个进程，扛全场

基于腾讯自研 harness-agent 运行时构建。单进程设计降低部署复杂度，同时保留多通道、多工具与多后端扩展能力，不依赖外部消息队列。

Agent Runtime

模型路由、工具调用、技能执行与对话检查点。

IM Bridge

飞书、钉钉、QQ、Discord、企业微信等通道接入。

Memory Store

分层召回与全文检索，记忆随工作区迁移。

Browser CDP

基于 CDP 的浏览器自动化，支持持久化登录态。

状态如何重建

进程内 HarnessProcessor 统一路由 Web UI、IM 与定时任务。整个状态在启动时从 ~/.octop/octop.db 重建，服务可重启恢复。

技术栈

Python 3.12+  ·  FastAPI + uvicorn  ·  harness-agent
harness-gateway  ·  SQLite (WAL) / PostgreSQL  ·  APScheduler
React 18 · TypeScript · Vite  ·  agent-client-protocol
Local FS · Docker · COS / S3
模块边界与依赖方向见仓库 AGENTS.md 与 docs/architecture.md。
