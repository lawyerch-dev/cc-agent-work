CLI

CLI

octop 命令行入口：init / run / user / agent / chats / cron 等。细节见 docs/cli.md。

octop init
octop run
octop agent list
octop chats send "hello"
CLI 信任本地文件系统访问 ~/.octop，无需 login。可用 --user / --agent 固定操作身份。
