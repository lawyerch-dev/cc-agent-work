从哪读起

如果你是第一次接触 Octop，建议路径：快速上手 → 架构总览 → 配置。开发者接入请直接看 HTTP API 与 Connectors。

1
安装

使用一键脚本或 Docker Compose 安装 Octop。

2
初始化

octop init 创建数据库、JWT 密钥与首个管理员。

3
启动

octop run 打开 http://127.0.0.1:8088。

默认管理员账号为 admin / octop，首次登录后请立刻修改密码。
# 一键安装（macOS / Linux）
curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | sh

# 初始化并启动
octop init
octop run
