Getting started

一分钟上手

安装 Octop，初始化本地状态，启动单进程服务。Web 控制台与 CLI 共用同一套数据。

系统要求

Python 3.12+（或使用 Docker）。macOS / Linux / Windows 均可。默认端口 8088。

安装

# 一键安装（macOS / Linux）
curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | sh

# Windows（PowerShell）
irm https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.ps1 | iex

初始化

# 创建数据库、JWT 密钥、首个管理员
octop init

启动

# 启动 API + Web 控制台
octop run

# 生产环境推荐 Docker
docker compose -f deploy/docker-compose.yml up -d
打开 http://127.0.0.1:8088，默认账号 admin / octop。请尽快在「设置 → 用户」中修改密码。

阅读架构总览了解单进程如何路由 Web、IM 与定时任务；或直接进入配置与环境。
