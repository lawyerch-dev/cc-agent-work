Configuration

配置与环境

config.json、环境变量、时区与存储后端。详细字段见仓库 docs/configuration.md。

要点

时区使用 default_timezone；语言不在 config.json 中，按用户偏好与 Accept-Language 解析。

# 环境变量示例
OCTOP_HOME=~/.octop
OCTOP_DEFAULT_TIMEZONE=Asia/Shanghai
完整配置项以仓库 docs/configuration.md 与 config.py 为准。
